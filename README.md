# CodeAlpha Network Sniffer

## About the Project
This project is a simple Network Sniffer developed using Python and Scapy. It captures network packets and displays useful information about them.

## Features
- Captures network packets.
- Displays Source IP and Destination IP.
- Identifies TCP and UDP protocols.
- Displays Source Port and Destination Port.
- Shows Packet Summary and Packet Size.
- Displays packet capturing start and end time.

## Technologies Used
- Python
- Scapy
- Npcap
- VS Code

## How to Run
1. Install Python.
2. Install Scapy using:

   `python -m pip install scapy`

3. Install Npcap on Windows.
4. Open the project folder in VS Code.
5. Run:

   `python network_sniffer.py`

## Project Purpose
The main purpose of this project is to understand how network packets travel and learn basic network traffic analysis.
